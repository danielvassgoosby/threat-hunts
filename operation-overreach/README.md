# Operation Overreach

Post-compromise threat hunt and incident investigation conducted in a hybrid Microsoft security environment.

## Environment

- Microsoft Defender XDR
- Microsoft Defender for Identity
- Microsoft Sentinel
- Microsoft Entra ID
- Log Analytics
- Active Directory
- KQL

## Investigation

This investigation began with a correlated high-severity incident involving a Finance account and progressed from cloud identity compromise into the on-premises environment.

The investigation included:

- Incident and alert triage
- Identity compromise analysis
- Session theft investigation
- Cloud-to-on-premises correlation
- VPN authentication analysis
- Active Directory investigation
- Credential-access hunting
- MITRE ATT&CK mapping
- Incident-response recommendations
